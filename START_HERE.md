# Sruthi Kamath — Fusion Dashboard

Quickest way: open `dashboard.html` in your browser. It works offline and needs no Python.

To run the Streamlit version, open a terminal in this folder and run:

```bash
python3 -m pip install -r requirements.txt && python3 -m streamlit run app.py
```

Both `app.py` and `dashboard.html` are self-contained and include the full interface and images.

The dashboard has eight pages in the sidebar. Start with Overview for the image and result, then move to whichever page you need. Patient details, tables and comparisons open on demand.

See `README.md` for the full description of each page, the data, and how to edit the code.
